# KM6312-Group-Project--Group5--2026Semester1
Machine learning analysis and prediction of bank term deposit subscriptions for the KM6312 Group Project.

## Dataset 
### Bank Marketing Dataset from UCI
This project uses the Bank Marketing dataset with social and economic context, created by Sérgio Moro, Paulo Cortez, and Paulo Rita (2014). 
This dataset is based on "Bank Marketing" UCI dataset (please check the description at: http://archive.ics.uci.edu/ml/datasets/Bank+Marketing).
The data is enriched by the addition of five new social and economic features/attributes (national wide indicators from a ~10M population country), published by the Banco de Portugal and publicly available at: https://www.bportugal.pt/estatisticasweb.
This dataset is publicly available for research. The details are described in [Moro et al., 2014]. 

The full dataset contains 41,188 observations and 20 input attributes, with the binary target `y` indicating whether a client subscribed to a term deposit.
